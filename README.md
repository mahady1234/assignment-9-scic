# User Directory Project

## Project Description
This project is a **User Directory web application** built with **Next.js 13** and **TailwindCSS**.  
It fetches user data from [JSONPlaceholder API](https://jsonplaceholder.typicode.com/users) and displays:  

- A **User Listing Page** showing all users in a responsive card grid  
- A **User Details Page** showing detailed contact, address, and company information  

The design is **modern, clean, and professional**, with hover effects, spacing, and readable fonts.
